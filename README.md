# Groundstation

Outils personnels pour préparer des environnements et rejouer des présentations.
Le nom vient de mes premiers essais autour de la télémétrie.

## Développement local

Copier `.env.example` vers `.env`, puis lancer `docker compose up -d`.
Le proxy local écoute sur le port 8080 ; le service de test sur le port 5678.
