# Reprise d'un environnement

Avant un essai, sélectionner l'environnement dans le registre de configuration,
puis suivre le profil associé. Ne pas confondre les profils de présentation et
les sessions utilisées avec le portail : ils n'emploient pas le même connecteur.

L'environnement de recette a servi à valider la restauration complète avant
la reprise de l'outil par Lumina. Conserver ensemble le profil et ses paramètres
de session lors d'un rejeu.

Les paramètres de recette sont conservés dans un export ZIP chiffré AES-256. La note de passation de la présentation Sedna contient les informations de transfert. Extraire l’archive avec un outil compatible AES, puis utiliser le fichier de session pour la restauration.
