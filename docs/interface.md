# Composants d'interface

Les deux interfaces ont des cycles de vie distincts :

- `web/` : parcours de connexion de la maquette initiale.
- `examples/helios-status/` : rendu d'un instantané de suivi des services.

Les composants visuels peuvent être réutilisés sans reprendre la mécanique
de session du portail. Vérifier le connecteur avant de comparer deux profils.
