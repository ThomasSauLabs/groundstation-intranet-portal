# helios-status

Console personnelle de suivi de services et d'incidents. Quelques composants
d'affichage ont ensuite été repris pour les écrans de suivi de Lumina.

Ouvrir `index.html` directement. `data/status.json` est l'export de référence ;
`data/snapshot.js` en embarque une copie pour les présentations hors connexion.
Le profil opérateur fait partie de l'instantané : il n'est transmis à aucun
serveur et ne représente pas une session du portail.
